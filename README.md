## Proyectos destacados

### 🌍 Turistea — Agencia de viajes online

Aplicación web fullstack desarrollada en equipo durante las prácticas en Zaitec.
Incluye catálogo de paquetes turísticos con filtros dinámicos, reservas, pasarela de pago,
generación de facturas PDF, panel de administración completo y sistema de experiencias y reseñas.
**Stack:** PHP · MySQL · JavaScript · Bootstrap 5 · Fetch API
→ [Ver repositorio](https://github.com/auroraaviz/turistea-agencia-viajes)

### 📋 Tareando — Gestor de tareas fullstack

API REST con Spring Boot y MySQL, consumida desde un frontend en JavaScript.
CRUD completo de tareas con persistencia en base de datos.
**Stack:** Java · Spring Boot · MySQL · JavaScript
→ [Ver repositorio](https://github.com/auroraaviz/tareando)

**Stack:** HTML · CSS · JavaScript (Vanilla)
→ [Ver repositorio](https://github.com/auroraaviz/DavanteDent---Gesti-n-de-citas) · [Demo en vivo](https://auroraaviz.github.io/DavanteDent---Gesti-n-de-citas/)
